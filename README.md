## Text statistics CLI

Use Python 3 to count the lines, words, and characters in a UTF-8 text file:

```text
python src/text_stats.py sample.txt
```

The program prints JSON, for example:

```json
{"lines": 5, "words": 14, "characters": 88}
```

Characters include line-ending characters, and words are runs of non-whitespace
characters.

Run the tests with Python's built-in `unittest` framework:

```text
python -m unittest discover -s tests
```
